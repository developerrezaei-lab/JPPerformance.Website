# نسخهٔ کاربردی وب‌سایت JP Performance

شاخه: feature/website-fitness-hub — مبنا master. این تغییر مربوط به وب‌سایت است.

## تغییرات

- حفظ هویت روشن و لیمویی، طراحی نشان و لوگوتایپ برداری JP، استفاده از فایل‌های SVG در header/footer/favicon.
- فونت‌های متغیر Manrope برای متن، Space Grotesk برای عنوان و Vazirmatn برای ورودی/متن فارسی. فونت‌ها به شکل WOFF2 از خود دامنه بارگذاری می‌شوند و مجوز OFL کنار فایل‌هاست.
- منوی واضح ابزارها، حرکات، ساخت برنامه و معرفی شرکت؛ بازنویسی مسیرهای صفحهٔ اصلی حول ابزارهای موجود.
- `/tools/`: BMI برای بزرگسالان ۲۰ سال به بالا، واحد متریک/امپریال، دسته‌بندی بر مبنای مقدار گردنشده، راهنمای محدودیت‌ها و تایمر استراحت.
- `/exercises/`: دوازده حرکت با طرح‌های شماتیک اصیل، جست‌وجو، فیلتر بدن/تجهیزات/تجربه، راهنمای کوتاه و لینک منبع، افزودن به برنامه.
- `/plans/`: الگوی قابل‌ویرایش دو/سه/چهارروزه با توجه به تجهیزات، تجربه و زمان در دسترس؛ انتخاب حرکت، تعداد ست/تکرار/استراحت، افزودن و حذف حرکت.
- `/plans/nutrition.html`: ایده‌های وعدهٔ سه/هفت‌روزه، تعداد افراد، ترجیح گیاهی یا ترکیبی، گزینهٔ سریع، فیلتر مواد اولیه، تعویض وعده، مواد و روش کلی آماده‌سازی و فهرست خرید تجمیعی.
- ذخیرهٔ صریح برنامه روی مرورگر، حذف نسخهٔ ذخیره‌شده، دانلود و ورود JSON اعتبارسنجی‌شده و چاپ/ذخیره PDF از پنجرهٔ چاپ مرورگر.
- به‌روزرسانی حریم خصوصی، شرایط، sitemap و پیوندهای داخلی.

## حدود عملکرد

محاسبهٔ BMI جای تشخیص، اندازه‌گیری چربی بدن یا ارزیابی پزشکی را نمی‌گیرد. برنامه‌ها الگوی عمومی و قابل‌ویرایش‌اند؛ برنامهٔ غذایی بر اساس سن/وزن/شرایط پزشکی کالری یا رژیم درمانی تجویز نمی‌کند. فیلتر مواد غذایی نمی‌تواند نبود آلرژن یا آلودگی متقاطع را تضمین کند. این موارد در همان صفحه‌ها توضیح داده شده‌اند.

BMI و تایمر در حافظهٔ همان تب محاسبه می‌شوند. برنامه‌ها فقط با انتخاب دکمهٔ ذخیره در localStorage می‌مانند. حساب ابری، پایگاه دادهٔ وب یا درخواست API برای اطلاعات کاربر وجود ندارد. خروجی‌ها کپی جداگانه‌اند. حالت بدون JavaScript فرم‌ها را غیرفعال نگه می‌دارد تا مقادیر شخصی ناخواسته با GET به سرور ارسال نشوند.

تصاویر حرکات شماتیک و ثابت‌اند؛ ویدئو یا آموزش کامل مربی نیستند. منابع راهنمای هر حرکت از NHS یا ACE در همان جزئیات لینک شده‌اند. تایمر اعلان یا صدای پس‌زمینه ندارد. تیک فهرست خرید موقت است و در فایل برنامه ذخیره نمی‌شود.

## بررسی

- ۵۶ تست محاسبه و مرزهای BMI، ارقام فارسی/عربی، ترکیب‌های تمرین، سازگاری تجهیزات/تجربه، تعادل اولیهٔ گروه‌های بالا/پایین‌تنه، برنامهٔ غذایی، فیلتر، مقیاس فهرست خرید و ورود/خروج برنامه پاس شدند.
- JavaScript syntax، مسیر فایل‌ها/فونت‌ها/لینک‌ها/fragmentها در ۱۲ صفحه و ساختار SVG بررسی شدند.
- در مرورگر: محاسبه و تبدیل واحد BMI، شروع/مکث تایمر، ایجاد و ویرایش ست و حفظ مقدار پس از reload، راهنمای حرکت، ایجاد/تعویض/ذخیرهٔ وعده، دانلود JSON و ورود دوبارهٔ همان فایل بررسی شدند.
- منوی موبایل و چیدمان در قاب‌های ۳۲۰ و ۳۹۰ پیکسل بررسی شدند. پنجرهٔ چاپ واقعی و مرورگرهای Safari/Firefox هنوز بررسی نشده‌اند.
- اجرای واقعی Docker/Nginx/Caddy در این محیط انجام نشده است؛ استقرار با سرور موجود باید انجام شود.

اجرای تست:

```bash
node tests/fitness-core.test.cjs
```

## دریافت روی سرور برای بررسی

```bash
(
set -e
cd /opt/jpperformance
git fetch origin
git switch feature/website-fitness-hub
git pull --ff-only origin feature/website-fitness-hub
docker compose up -d --force-recreate --wait --wait-timeout 90
docker compose ps
)
```

این دستور سایت عمومی را به نسخهٔ شاخهٔ وب تغییر می‌دهد؛ بلوک Caddy دوباره اضافه نمی‌شود. ابتدا تغییرات commitنشدهٔ سرور را با `git status --short` بررسی کنید. برای انتشار نهایی، پس از بررسی، شاخه به master ادغام و سرور به master بازگردانده می‌شود.

مسیر سایت: `/opt/jpperformance`؛ شبکهٔ مشترک `hosting-edge`؛ ورودی `hosting-edge-caddy-1`؛ Caddyfile در `/opt/kpdc/deploy/hetzner/edge/config/Caddyfile`.
