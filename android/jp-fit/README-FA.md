# JP Fit — نسخهٔ آزمایشی اندروید ۰٫۱٫۰

پروژهٔ مستقل Android در همان مخزن شرکت، در مسیر `android/jp-fit` قرار دارد. این اپ بومی Android است؛ WebView یا بسته‌بندی سایت نیست. از Java و Viewهای بومی سیستم استفاده می‌کند و هیچ کتابخانهٔ اجرایی شخص ثالثی ندارد.

## امکانات پیاده‌شده

- شروع، ادامه و پایان جلسهٔ تمرین؛ حفظ جلسهٔ ناتمام بعد از بسته‌شدن اپ.
- فهرست اولیهٔ حرکت‌ها و امکان ورود نام حرکت دلخواه.
- ثبت، ویرایش و حذف ست‌ها با تعداد تکرار و وزن به کیلوگرم.
- پذیرش ارقام فارسی و عربی؛ کنترل ورودی خالی، مقادیر منفی، NaN و Infinity.
- تایمر استراحت ۳۰، ۶۰، ۹۰، ۱۲۰ یا ۱۸۰ ثانیه؛ مکث، ادامه و بازنشانی.
- نگهداری زمان پایان تایمر؛ بازگشت از پس‌زمینه شمارش را مطابق زمان واقعی به‌روز می‌کند. این نسخه اعلان/صدای پایان در پس‌زمینه ندارد.
- تاریخچهٔ جلسات، جزئیات ست‌ها و حذف جلسه با تأیید.
- جمع جلسه‌ها و ست‌ها و نمودار میله‌ای حجم وزنه در ۷ جلسهٔ اخیر. حجم برابر تکرار × وزن ثبت‌شده است؛ معیار سلامت یا مقایسهٔ حرکت‌های متفاوت نیست.
- زبان فارسی و انگلیسی، راست‌به‌چپ، حالت روشن/تاریک/مطابق سیستم؛ پیش‌فرض تاریک.
- خروجی JSON با انتخاب محل ذخیره از فایل‌منیجر سیستم. بازیابی فایل هنوز پیاده نشده است.
- حذف همهٔ اطلاعات تمرین و توضیح حریم خصوصی داخل اپ.

## داده و دسترسی

SQLite خصوصی برنامه محل نگهداری اطلاعات است. هیچ مجوز INTERNET، شناسهٔ دستگاه، Firebase، AdMob، Health Connect، حساب کاربری یا سرور ابری در این نسخه وجود ندارد. فایل خروجی پس از انتخاب کاربر می‌تواند در ارائه‌دهندهٔ فایل محلی یا ابری ذخیره شود. با حذف داده‌های داخل اپ، نسخه‌های خروجی قبلی حذف نمی‌شوند.

نام موقت اپ JP Fit و applicationId فعلی `uk.co.jpperformance.fit` است. قبل از اولین انتشار شناسه، نام نهایی، آیکن و کلید امضا باید تثبیت شوند.

## دریافت روی ویندوز

در پوشهٔ فعلی پروژه:

```powershell
cd F:\Apps\AmBusiness\JPPerformance.Website
git fetch origin
git switch --track origin/feature/jp-fit-android-mvp
cd android\jp-fit
```

اگر شاخه قبلاً روی لوکال ساخته شده، به‌جای دستور `switch --track` از `git switch feature/jp-fit-android-mvp` و `git pull --ff-only` استفاده کنید. اگر تغییر commitنشده دارید، قبل از جابه‌جایی شاخه آن‌ها را بررسی و نگهداری کنید.

## ساخت APK

پیش‌نیازها: Android Studio سازگار با AGP 8.13، JDK حداقل 17، Android SDK Platform 36 و Build Tools 35.0.0. Gradle Wrapper 8.13 و SHA-256 توزیع در مخزن قرار دارند. اولین build به دانلود Gradle و وابستگی‌های رسمی Google/Maven نیاز دارد.

پوشهٔ `android/jp-fit` را در Android Studio باز کنید و اجازه دهید Sync کامل شود. سپس Build APK را اجرا کنید؛ یا در PowerShell:

```powershell
.\Build-Android.ps1
```

نصب روی یک گوشی متصل با USB debugging:

```powershell
.\Build-Android.ps1 -Install
```

بدون اسکریپت نیز می‌توان اجرا کرد:

```powershell
.\gradlew.bat :app:assembleDebug
```

خروجی معمول Gradle:

```text
app\build\outputs\apk\debug\app-debug.apk
```

APK آزمایشی ساخته‌شده در محیط آماده‌سازی از کلید موقت debug استفاده می‌کند؛ کلید موقت برای انتشار Play استفاده نشود. اگر APK آزمایشی این جلسه را قبلاً نصب کرده‌اید، ممکن است کلید build محلی متفاوت باشد؛ در این حالت قبل از حذف نسخهٔ قبلی، اطلاعات لازم را خروجی بگیرید. حذف نصب، داده‌های محلی را پاک می‌کند.

برای Google Play، باید AAB با کلید upload پایدار و مورد کنترل شرکت ساخته شود. هیچ کلید تولید، رمز یا keystore در Git قرار نگرفته است. این نسخه هنوز روی دستگاه واقعی یا شبیه‌ساز آزموده نشده و آمادهٔ انتشار عمومی اعلام نمی‌شود.

## آزمون‌ها

تست مستقل `tests/WorkoutRulesTest.java` شامل ۲۱ بررسی ورودی‌های فارسی/عربی، مرزهای مقادیر، ورودی نامعتبر و مرزهای تایمر است. در یک JDK کامل:

```powershell
New-Item -ItemType Directory -Force build\rules | Out-Null
javac -encoding UTF-8 -d build\rules app\src\main\java\uk\co\jpperformance\fit\WorkoutRules.java tests\WorkoutRulesTest.java
java -cp build\rules uk.co.jpperformance.fit.WorkoutRulesTest
```

برای رفتار SQLite و رابط، چک‌لیست `TESTING-FA.md` را روی گوشی اجرا کنید.
